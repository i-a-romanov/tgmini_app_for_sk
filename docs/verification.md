# Проверка рабочего MVP

22 ноября 2026. Рабочая версия: `public/` и `server/`; исходные макеты: `output/design/`.

## Проверено

Итог: **26 автоматических тестов прошли**, полный browser-сценарий прошёл. `render.yaml` прошёл проверку официальной JSON Schema. Чистая установка `npm ci --omit=dev` в отдельной папке и импорт серверных модулей успешны; npm audit не обнаружил известных уязвимостей в установленном наборе.

- Сервер и SQL проверяются на PostgreSQL-движке PGlite, не на JavaScript-заглушке SQL.
- HMAC и возраст `initData`, Unicode, большой ID, повторные поля, неверный токен, подмена пользователя.
- Сессии, Origin, CSRF, запрет тестового входа на Render и production.
- Сохранение между сессиями, конфликт устаревших настроек, валидация времени и timezone.
- Идемпотентная активация и выполнение, неверный ответ, чек-листы, доступ только к задачам своего маршрута.
- Изоляция дедлайнов, проверка владельца экспорта, срок ссылки 5 минут, отзыв при удалении профиля.
- Секрет webhook, дедупликация, `/start` до первого входа, `/stop`.
- Напоминания: timezone, граница дня, окно отправки, дневная дедупликация.
- Удаление данных и сессий; повторный вход создаёт новый пустой профиль.
- Browser-сценарий с HTTP, SQL и подписанной тестовой авторизацией: онбординг, задания, черновик после reload, даты, календарь, темы, 320px, sharing и удаление.
- Визуальная проверка рабочих экранов; исправлен конфликт класса нативного режима со стилями исходного заголовка.

## Команды

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
node scripts/check-render.mjs
```

Проверка Render использует официальную JSON Schema и требует интернет. Для офлайн-схемы задайте `RENDER_SCHEMA_FILE`. Для установленного Chromium-браузера задайте `CHROME_PATH`.

## Границы проверки

В browser-тесте заменён только Telegram host bridge: MainButton, тема и загрузка файла. Подпись, HTTP и SQL настоящие; пользователь и токен тестовые. Реальные Telegram API, доставка сообщений, native iOS/Android и ваш Render ещё не проверены: необходимы ваш бот, токен в Environment и деплой.

PGlite проверяет SQL, но не сетевое соединение с Render PostgreSQL. `/healthz` проверит его после запуска. Критерии и даты приёмной комиссии не подтверждались; приложение не выдаёт их за проверенные.

Старый `sk-fast-track-design-kit.zip` содержит дизайн-концепт. Для развёртывания используйте текущий репозиторий или `sk-fast-track-render.zip`.
